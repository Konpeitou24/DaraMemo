# backend直下

このディレクトリは、**アプリケーション全体の実行エントリポイント**を提供します。  
DaraMemoのバックエンドを起動する際は、この `main.py` を実行することで、AFK監視機能とAPIサーバーの両方が一括で起動されます。

---

## main.py

このファイルは、アプリケーションの**メイン関数**を定義し、`core/runtime.py` によってアプリケーション全体を起動します。  
Pythonスクリプトとして直接実行された場合、`__main__` ブロックが実行され、ログ出力の初期化とともにアプリケーションが開始されます。

---

### 主な構成

- **main() 関数**  
  `Runtime` クラスのインスタンスを生成し、`.run()` メソッドでアプリケーションの起動と管理を委任します。

- **`if __name__ == "__main__"` ブロック**  
  このファイルがスクリプトとして実行されたときに実行される特殊な構文です。ログ設定を行ったうえで `main()` を呼び出します。

- **logging.basicConfig(level=logging.INFO)**  
  ログ出力のレベルを INFO に設定します。これにより、アプリケーション起動時の各種情報が標準出力に表示されるようになります。

---

### 用語解説

- **エントリポイント**  
  プログラムの実行開始点のことです。Pythonでは通常 `main.py` や `if __name__ == "__main__"` ブロックがこれに該当します。

- **main() 関数**  
  アプリケーションの開始処理をまとめた関数です。慣習的に `main` と名付けられることが多いです。

- **Runtime クラス**  
  AFK監視アプリケーションとAPIサーバーを同時に起動・管理する役割を持つクラスです。詳細は `core/runtime.py` を参照してください。

- **logging（ロギング）モジュール**  
  Python標準のログ出力機能です。アプリケーションの状態やエラー情報を記録・表示するために使用されます。

- **INFOレベル**  
  ログの重要度を示す指標の一つで、「通常の情報出力」を意味します。エラーほどではないが、ユーザーや開発者が知っておくと良い情報に使われます。
