# `core` フォルダー

## runtime.py

このファイルでは、アプリケーション本体とAPIサーバーをまとめて起動・管理する `Runtime` クラスが定義されています。

起動順序の制御、スレッドによる非同期実行、終了処理などを一括して扱う「実行統括用」のクラスです。



### 主な構成

- **Runtime クラス**  
  アプリケーションとAPIサーバーの起動・停止処理をまとめて管理するクラスです。  
  実行中に `Ctrl + C` などで終了要求があったときも安全に停止するよう設計されています。

- **__init__()**  
  `Application`（AFK監視）と `Api`（Flask API）を初期化します。

- **run()**  
  - APIを起動します（`self.api.run()`）  
  - アプリケーションを別スレッドで起動します（`self.application.run()`）  
  - `Ctrl + C` が押されたときにシャットダウン処理が走るよう、メインスレッドで `join()` を監視します  
  - 終了時にはアプリ→APIの順で停止処理を行います



### 用語解説

- **スレッド（`threading.Thread`）**  
  プログラム内で複数の処理を「同時に動かす」仕組みです。  
  ここではアプリケーション（キーボード／マウス監視など）を別スレッドで動かすことで、APIと並行実行できるようにしています。

- **join()**  
  他のスレッドが終了するのを待つための関数です。  
  `timeout=0.5` とすることで、0.5秒ごとに `Ctrl+C` を受け取れるようにしています。

- **KeyboardInterrupt**  
  ユーザーが `Ctrl+C` を押したときに発生する例外です。これを `try/except` で受け取って安全に終了処理を行います。

- **finally ブロック**  
  `try/except` の後に実行される処理です。ここでAPIの停止処理など「必ずやるべき終了処理」を書いています。

- **ロガー（logging）**  
  プログラムの進行状況や異常系の記録を残すための機能です。  
  実行中・終了時のログがコンソールなどに表示され、デバッグにも使われます。
