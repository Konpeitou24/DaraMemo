# requirements.txt

このファイルは、**DaraMemo バックエンド**で使用される Python ライブラリの一覧を記述したものです。  
ここに記載されたライブラリは、**すべての開発者・ユーザーが共通の動作環境を再現できるようにするための設計**です。

---

## インストール方法（必ず仮想環境内で実行）

このプロジェクトでは、**Python 仮想環境（venv）上で依存関係をインストールして実行することが前提**です。  
仮想環境を使わずにインストールした場合、**他のプロジェクトとライブラリの競合が発生する恐れがあり、ビルド・実行時に不具合を引き起こす可能性があります。**

### 【Step 1】仮想環境の作成（初回のみ）

```bash
python -m venv .venv
```

> `python` は Python 3.10 以降が推奨です。必要に応じて `py -3.12` などを指定してください。

### 【Step 2】仮想環境の有効化

- **Windows（PowerShell）**:

```bash
.venv\Scripts\Activate.ps1
```

- **Windows（コマンドプロンプト）**:

```cmd
.venv\Scripts\activate.bat
```

- **macOS / Linux**:

```bash
source .venv/bin/activate
```

> 仮想環境に入ると、プロンプトの先頭に `(.venv)` のような表示が付きます。

### 【Step 3】依存ライブラリのインストール

```bash
pip install -r requirements.txt
```

## 用語解説

- **仮想環境（venv）**  
  プロジェクトごとに独立した Python ライブラリの実行環境を構築するための仕組みです。異なるプロジェクト間でライブラリのバージョンが衝突するのを防ぎます。

- **バージョン固定（ピン留め）**  
  `Flask==3.1.1` のように `==` を使ってインストールするライブラリのバージョンを明示的に指定します。これにより、将来のバージョンアップによる不具合を防ぎ、再現性のある開発環境が構築できます。

- **依存関係（依存ライブラリ）**  
  あるライブラリが内部的に別のライブラリを必要とする関係を指します。例：`Flask` は内部的に `Werkzeug` や `Jinja2` を利用しています。

- **ORM（Object Relational Mapper）**  
  SQL を直接書かずに、Python のクラスとデータベースを連携させて扱うための仕組みです。`SQLAlchemy` によって実現されます。


## 注意事項

- **仮想環境を有効にせずに `pip install` を実行すると、システム全体にライブラリがインストールされてしまう可能性があります。**  
  これは、他の Python プロジェクトに予期しない影響を及ぼす原因となるため、必ず `.venv` を使用してください。

- 本ファイルは `requirements.txt` に基づき自動で生成できます。  
  ライブラリ追加後に更新する場合は、以下のコマンドを使用してください：

```bash
pip freeze > requirements.txt
```
