# build.ps1

このスクリプトは、DaraMemo バックエンドの Python アプリケーションを **Windows 向けに実行ファイル（.exe）としてビルドする** ための PowerShell スクリプトです。  
Python → バイナリ形式への変換には `Nuitka` を使用しており、ビルド成果物は `./bin` ディレクトリに出力されます。

---

## 主な構成

- **カレントディレクトリの保存と復元**  
  実行前の作業ディレクトリを一時保存し、処理後に復元することで、作業中の他のシェル環境へ影響を与えないようにしています。

- **プロジェクトルートへの移動**  
  `$PSScriptRoot` を使って、スクリプトファイルの存在する `public/` フォルダからプロジェクトルートに移動します。

- **仮想環境の有効化**  
  以下の候補から `Activate.ps1` を検索し、最初に見つかった仮想環境を有効化します。
  - `.venv/Scripts/Activate.ps1`
  - `venv/Scripts/Activate.ps1`
  - `env/Scripts/Activate.ps1`
  - `.env/Scripts/Activate.ps1`

  該当するものが見つからなかった場合は、ビルドを中止しエラーメッセージを出力します。

- **bin ディレクトリの作成**  
  ビルド成果物を格納するために、`./bin` フォルダの存在を確認し、存在しない場合は自動で作成します。

- **Nuitka によるビルド**  
  `main.py` をビルド対象とし、Nuitka を使って次のようにビルドを行います：
  - `--onefile`：単一の `.exe` にバンドル
  - `--windows-console-mode=disable`：GUIアプリとしてビルド（黒いコンソール画面を抑制）
  - `--output-dir=bin`：出力先フォルダを `./bin` に指定

- **ログ出力**  
  各ステップで `[INFO]` や `[ERROR]` などのログ出力があり、実行状況が把握しやすくなっています。

## 用語解説

- **PowerShell**  
  Windows のスクリプト実行環境で、`.ps1` ファイル形式のスクリプトを通じてファイル操作やビルドなどの自動処理を実行できます。

- **仮想環境（venv）**  
  Python の依存関係をプロジェクト単位で分離するための仕組みです。本プロジェクトではこの仮想環境に `Nuitka` などのビルド依存パッケージをインストールしています。

- **Nuitka**  
  Python スクリプトを C 言語に変換して、ネイティブな `.exe` ファイルにコンパイルするツールです。実行速度の向上やソースコードの保護にも役立ちます。

- **`--onefile` オプション**  
  複数のバイナリやリソースファイルをすべて1つの `.exe` にまとめるオプションです。配布が容易になる利点があります。

- **`--windows-console-mode=disable`**  
  GUIアプリケーションとしてビルドするためのオプションです。これを指定することで、実行時に黒いコンソールウィンドウが表示されなくなります。

- **`Set-Location` / `Get-Location`**  
  PowerShell におけるカレントディレクトリ（作業ディレクトリ）の取得・変更を行うコマンドレットです。

## 互換性と注意点

- **PowerShell 7 以降を推奨**  
  `$PSScriptRoot` の取り扱いやエラー制御の挙動に関して、一部の環境（特に PowerShell 5.x 以前）では正しく動作しないことがあります。  
  そのため、**PowerShell 7 以降の使用を推奨**します。

  バージョン確認方法：

  ```powershell
  $PSVersionTable.PSVersion
  ```

  PowerShell 7 のインストールはこちら：  
  https://github.com/PowerShell/PowerShell

- **Windows 専用スクリプト**  
  `.ps1` ファイルは Windows 専用であり、Linux/macOS では `.sh` や `Makefile` などを用意する必要があります。

- **Nuitka の事前インストールが必要**  
  仮想環境内に `nuitka` パッケージがインストールされていないとビルドに失敗します。  
  以下のコマンドでインストールできます：

  ```powershell
  pip install nuitka
  ```

## 補足

- ビルド成果物は `/bin` フォルダ以下に出力され、`.exe` ファイルとして配布可能になります。
- 本番環境向けの最適化オプション（`--nofollow-imports` など）の追加は、今後の運用フェーズで検討可能です。
- PyInstaller と異なり、Nuitka は実行速度の向上やコンパイルによるコード難読化の面でもメリットがあります。
