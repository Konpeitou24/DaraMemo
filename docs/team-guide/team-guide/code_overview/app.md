# `app` フォルダー

## application.py

このファイルには、アプリケーションの実行全体を管理する `Application` クラスが定義されています。  
メイン処理ループの起動・停止、タイマーの制御などを行います。  
裏で定期的に実行したい処理（例：AFK状態のチェックなど）をセットアップする土台です。

### 主な構成

- **Application クラス**  
  アプリケーション全体の起動・停止・ループ処理・タイマー制御を管理します。

- **__init__(fps=60)**  
  アプリケーションの初期設定を行います。  
  引数 `fps` は「1秒間に何回更新するか」を指定するもので、ゲームやアニメーションの“フレームレート”の考え方と同じです。  
  この値を使って `tick_interval`（1回の待機時間）を計算します。

- **run()**  
  アプリケーションを開始するメソッドです。  
  タイマーを起動し、メインループを実行します。

- **shutdown()**  
  アプリケーションの停止処理を行います。  
  タイマーを停止し、`should_run` を `False` にします。

- **_main_loop()**  
  `should_run` が `True` の間、ループ処理を実行し続けます。  
  指定された間隔 (`tick_interval`) ごとに1回ずつループします。

- **_on_tick()**  
  非同期タイマーから呼ばれるコールバック関数です。  
  1秒に1回、ログに「tickが発生した」ことを記録するだけの簡単な処理です（今後拡張される想定）。



### 用語解説

- **フレームレート（fps）**  
  「1秒あたり何回処理を行うか」という考え方です。  
  たとえば fps=60 なら、毎秒60回のループ更新を行います。ゲームや映像でよく使われる単位です。

- **tick_interval**  
  `fps` に基づいて計算された、1回のループの待機時間（秒単位）です。  
  たとえば fps=60 なら `tick_interval = 1 / 60 = 約0.016秒`。

- **タイマー（NonBlockingTimer）**  
  別スレッドで動作し、一定時間ごとに指定した関数（コールバック）を呼び出してくれる仕組みです。  
  `Application` クラスでは、これを使って「1秒ごとにAFK判定などを行う」設計になっています。

- **should_run**  
  アプリケーションが動いているかどうかを管理するフラグ（真偽値）です。  
  `True` のときだけメインループが動きます。

- **ログ（logging）**  
  アプリの動作状況を記録するための仕組みです。  
  たとえば `Application is starting...` のような出力は、開発中やトラブル時に状況を確認するために使われます。

- **コールバック関数**  
  「あとで呼び出すために渡しておく関数」のことです。  
  `NonBlockingTimer` に渡された `self._on_tick` は、1秒ごとに呼び出される処理です。

## core/mouse_activity_detector.py

このファイルでは、マウスが動いたりクリックされたことを検知する `MouseActivityDetector` クラスが定義されています。

一定間隔ごとに「この間にマウスが動いたか／クリックされたか？」をチェックするための処理が含まれています。

これはAFK（離席）状態を判定するための補助的なモジュールです。



### 主な構成

- **MouseActivityDetector クラス**  
  マウスの移動またはクリックを検知し、それが「検知されたかどうか」を `True/False` で返すクラス。

- **__init__(interval=1.0)**  
  マウス操作の検知に使うリスナーを作成し、バックグラウンドで常時動作させます。  
  引数 `interval` は、「どのくらいの間隔でマウス操作を確認するか（秒）」を指定します。

- **_on_move(x, y)**  
  マウスが動いたときに呼び出される関数です。フラグ `_moved` を `True` にします。

- **_on_click(x, y, button, pressed)**  
  マウスがクリックされたときに呼び出される関数です。ボタンが押されたときに `_clicked` を `True` にします。

- **is_moved()**  
  `interval` 秒の間にマウスが動いたかどうかを返すメソッドです。

- **is_clicked()**  
  `interval` 秒の間にマウスがクリックされたかどうかを返すメソッドです。

- **_check_flag(flag_name)**  
  `_moved` または `_clicked` を対象として、いったんリセットし、`interval` 秒待機してから結果を返す内部用関数です。



### 用語解説

- **AFK（Away From Keyboard）**  
  パソコンの前から離れている状態を指します。このアプリでは、マウスやキーボードがしばらく動いていないと「離席している」と判断します。

- **pynput**  
  マウスやキーボードの動きをプログラムから監視するためのPythonライブラリです。  
  Windows / macOS / Linux すべてに対応しており、非同期に監視できます。

- **マウスリスナー（`mouse.Listener`）**  
  マウスの動きやクリックを検知するための機能です。`_on_move()` や `_on_click()` を呼び出すトリガーになります。  
  アプリが動いている間、バックグラウンドでずっと動いています。

- **スレッドロック（`threading.Lock`）**  
  同時にアクセスされるデータ（ここでは `_moved` や `_clicked`）を安全に扱うための仕組みです。  
  複数の処理が同時に動いていても、データが壊れないようにします。

- **sleep（`time.sleep()`）**  
  プログラムの動作を一時停止する命令です。ここでは一定時間観察するために使われます。  
  `sleep(1.0)` なら、1秒間だけ止まります。

- **setattr / getattr**  
  変数名（文字列）を使って、その変数の値を設定・取得するPythonの組み込み関数です。  
  ここでは `_moved` や `_clicked` というフラグの操作に使っています。



このモジュールは、アプリケーション側から「最近マウス使ってた？」と尋ねる役割を担っています。  
あくまで **「状態を記録し、後からチェックする」** という補助的な立ち位置です。

## core/keyboard_activity_detector.py

このファイルでは、キーボードの入力があったかどうかを一定間隔でチェックできる `KeyboardActivityDetector` クラスが定義されています。

「この間にキーボードを一度でも押したかどうか？」を判定し、AFK（離席）かどうかを確認するための補助的な仕組みとして使われます。



### 主な構成

- **KeyboardActivityDetector クラス**  
  キー入力があったかどうかを監視し、必要に応じて判定するクラスです。

- **__init__(interval=1.0)**  
  クラスの初期化処理です。監視間隔（秒）を設定し、`pynput.keyboard.Listener` を起動します。キーが押された瞬間に `_on_press()` が呼び出されるように設定されます。

- **_on_press(key)**  
  ユーザーがキーを押すと、この関数が呼び出され、内部の `_pressed` フラグが `True` になります。

- **is_pressed()**  
  `interval` 秒間キー入力があったかどうかを確認し、その結果を返します。チェック後は `_pressed` フラグがリセットされ、次回のチェックに備えます。



### 用語解説

- **AFK（Away From Keyboard）**  
  パソコンの前にいない状態のことです。このアプリでは、マウスやキーボードの操作が一定時間なければ「離席中」とみなします。

- **pynput**  
  マウスやキーボードの操作を監視するためのPythonライブラリです。裏で常に動き続け、ユーザーの入力をリアルタイムで検出できます。

- **キーボードリスナー（`keyboard.Listener`）**  
  キーが押された瞬間に自動で関数（ここでは `_on_press()`）を呼び出す仕組みです。リスナーはバックグラウンドでずっと動作しています。

- **スレッドロック（`threading.Lock`）**  
  複数の処理が同時に `self._pressed` を読んだり書いたりしても、データが壊れないように保護するための仕組みです。

- **sleep（`time.sleep()`）**  
  一定時間だけプログラムの実行を止める関数です。ここでは `interval` 秒だけ待機し、その間にキー入力があればフラグが立ちます。

- **フラグ（`_pressed`）**  
  「キーが押されたかどうか」を記録する変数です。初期化直後は `False` ですが、入力があると `True` になります。チェックが終わるたびに手動でリセットされます。

## core/afk_service.py

このファイルには、ユーザーが「離席中（AFK）」かどうかを判定する `AfkService` クラスが定義されています。

マウスやキーボードの操作を一定間隔でチェックし、「この間に1回でも操作があったかどうか」を調べる機能を提供します。

これは実際にAFK状態を検出する処理の土台として使われます。



### 主な構成

- **AfkService クラス**  
  ユーザーがマウスやキーボードを使っているかどうかを定期的に調べるクラスです。  
  マウス／キーボードをそれぞれ専用のクラスで監視し、その2つをまとめて扱います。

- **__init__(interval)**  
  クラスの初期化処理です。  
  `interval` は「何秒ごとにAFK状態をチェックするか」を指定する値です。  
  内部では `KeyboardActivityDetector` と `MouseActivityDetector` をそれぞれ初期化して、同じ間隔で監視を行います。



### 用語解説

- **AFK（Away From Keyboard）**  
  パソコンの前から離れている状態のことです。  
  このアプリでは、「一定時間キーボードやマウスの操作がなければAFK」と判断します。

- **サービスクラス**  
  アプリ全体で使う特定の処理をまとめて管理するためのクラスです。ここでは「AFKをチェックする」という目的のためだけに存在します。

- **インスタンス**  
  クラスから作られた「実体（オブジェクト）」のことです。  
  ここでは `KeyboardActivityDetector` や `MouseActivityDetector` を初期化して、それぞれの入力を監視します。

- **引数 `interval`**  
  チェック間隔（秒数）です。たとえば `interval=1.0` なら、1秒に1回「操作があったかどうか」を調べます。

- **バリデーション（`if interval <= 0:`）**  
  値が正しいかを確認する処理です。`interval` が0秒以下だと監視できないので、例外を出して止めています。
